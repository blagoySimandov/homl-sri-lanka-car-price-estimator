# Sri Lanka Used Car Price Estimator

A machine learning model that predicts used car prices in the Sri Lankan market.

## What This Project Covers

- **Data Cleaning** — Handling missing values and inconsistencies
- **Preprocessing** — Encoding categorical variables and scaling features
- **Feature Selection** — Identifying the most important predictors
- **Model Selection** — Comparing multiple regression algorithms

## Models Tested

- Linear Regression
- Random Forest
- Gradient Boosting
